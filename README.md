# 🛒 MarketPanel

**MarketPanel** is a modern, fast, and responsive admin dashboard designed for grocery eCommerce platforms.  
It provides a clean and scalable interface to manage products, orders, customers, inventory, and analytics — built with **React**, **Vite**, and **Tailwind CSS v4**.

---

## 🚀 Tech Stack

- **React** – UI library
- **Vite** – Lightning-fast build tool
- **Tailwind CSS v4** – Utility-first modern styling
- **JavaScript / TypeScript** (optional)
- **ESLint + Prettier** (recommended)

---

## ✨ Features

- 📊 Dashboard analytics & sales overview  
- 🛒 Order management  
- 📦 Product & inventory management  
- 👥 Customer management  
- 🔐 Admin-ready layout  
- 📱 Fully responsive design  
- ⚡ Optimized performance with Vite  
- 🎨 Clean, modern UI with Tailwind CSS v4

## 🛠️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/hadiarabnejad/MarketPanel
cd MarketPanel
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the development server

```bash
npm run dev
```

The app will be available at:

```
http://localhost:5173
```

---

## 🏗️ Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
